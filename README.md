# Custodia Compartida App

App completa de gestión de custodia compartida con calendario y solicitudes.

## Funcionalidades
- 🏠 **Home**: Calendario completo (funcionalidad original)
- 📄 **Solicitudes**: Lista todas las solicitudes con opción de cancelar las pendientes
- 📆 **Eventos**: Lista visual de eventos ordenados por fecha

## Instalación
1. Sube estos archivos a tu hosting (Firebase, Netlify, etc.)
2. Configura Firebase si usas Firestore
3. ¡Listo!

## Adaptación
- Copia tu CSS completo en `index.html`
- Copia tu HTML del calendario en `#view-home`
- Adapta `obtenerMisSolicitudes()` y `obtenerEventosCalendario()` a tu código
