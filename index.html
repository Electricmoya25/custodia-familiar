Para proteger tu aplicación, debes configurar Firebase correctamente antes de usarla.

Pasos para Configurar Firebase

Crear un proyecto en Firebase Console
Registrar una aplicación web en tu proyecto de Firebase
Copiar tu configuración de Firebase (firebaseConfig)
Reemplazar la configuración de ejemplo en el archivo index.html

¿Por qué es esto importante?

  • Las claves expuestas pueden ser usadas para acceder a tu base de datos
  • Podrían generar cargos no autorizados en tu cuenta de Google Cloud
